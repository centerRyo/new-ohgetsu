# 案1「食品表示スキャンアプリ」需要検証ヒアリング計画

> `allergy-new-business-proposal.md` で推奨した案1(食品表示スキャンアプリ「特定原材料チェッカー」)について、開発着手前に行う需要検証の設計。1対1インタビューでニーズの解像度を上げ、その後アンケートで定量検証する2段階構成。

| 項目 | 内容 |
|---|---|
| 検証したい仮説 | 食物アレルギー当事者・保護者は、店頭での加工食品購入時にアレルゲン確認で困っており、月額課金してでも解決したいと思うほどの強い痛みがある |
| 対象 | 食物アレルギーのある子どもを持つ保護者 / 成人の食物アレルギー当事者 |
| リーチ手段 | SNS当事者コミュニティ・知人紹介(インタビュー) → オンライン調査会社(アンケート) |
| 形式 | Phase 1: 1対1インタビュー(10〜15人) → Phase 2: アンケート(50〜100人規模) |

---

## 全体の進め方

```
Phase 1: デプスインタビュー(1〜2週目)
  ├ 10〜15人と1対1で30分程度
  ├ 目的: 痛みの実態・言葉遣い・既存の代替手段を深く理解する
  └ 出力: 定性的な発見、Phase 2の設問設計への反映

Phase 2: アンケート(3〜4週目)
  ├ 50〜100人規模、オンライン調査会社 or クラウドソーシング
  ├ 目的: Phase 1の仮説を定量的に裏付ける(支払い意思・優先度の分布)
  └ 出力: Go/No-Goの判断材料、価格帯・機能優先順位の数値的根拠
```

Phase 1を先に行うのは、質問票を「作り手の思い込み」ではなく「当事者の実際の言葉」で設計するため。Phase 2の設問はPhase 1の結果を踏まえて微調整する前提とする。

---

## Phase 1: デプスインタビュー ガイド(1対1・30分想定)

### 進め方の原則

- **誘導しない**: 「バーコードスキャンアプリがあったら使いますか？」のような聞き方は避ける。先にアプリの存在を明かさず、現状の行動と困りごとから聞く。
- **具体的なエピソードを掘る**: 「困っています」で終わらせず、「直近でいつ、どこで、何が起きたか」を聞く。
- **支払い意思は最後に、かつ具体額で聞く**: 「お金を払いますか」ではなく「月300円ならどうか、月1,000円ならどうか」と具体額を当てて反応を見る。

### 対象者スクリーニング(事前に確認)

- 食物アレルギー当事者本人、または未成年の子どもの食物アレルギーに対応している保護者
- 直近1ヶ月以内にスーパー・コンビニで加工食品を購入した経験がある
- 対応歴(診断からの期間)を軽くヒアリングし、初心者層(診断1年未満)とベテラン層(3年以上)のバランスを取る — 困りごとの質が変わりやすいため

### 質問票(全15問)

**A. 導入・現状把握(アプリの話はまだしない)**

1. まず、どなたのどんな食物アレルギーに対応されているか教えてください。(本人/お子様、アレルゲンの種類、診断からの期間)
2. 普段、加工食品(お菓子・レトルト・冷凍食品など)を買うのはどこが多いですか？(スーパー/コンビニ/ネットスーパー/生協 等)
3. 新しい商品を買うとき、アレルゲン表示はどうやって確認していますか？(パッケージを見る/メーカーサイトを見る/慣れた商品しか買わない 等、具体的な手順を聞く)

**B. 困りごとの深掘り**

4. 直近1ヶ月で、「これ食べさせて(食べて)大丈夫かな」と迷った・確認に手間取った具体的な出来事を教えてください。(場所、商品、何に時間がかかったか)
5. その確認作業に、実際どれくらい時間がかかりましたか？(店頭で/家に帰ってから)
6. 確認した結果、「結局分からなかった」「買うのをやめた」という経験はありますか？そのときどう感じましたか？
7. お子様(または他の家族)に食品を渡す際、確認漏れでヒヤッとした経験はありますか？(あれば詳しく)
8. 表示を見ても分かりにくいと感じるのはどんなときですか？(コンタミ表示、原材料名が専門的、推奨20品目まで書いていない 等)

**C. 既存の代替手段の満足度**

9. 今使っている確認方法(メーカー公式サイト、Cookpad的なもの、慣れた商品リスト等)に対して、満足していますか？不満な点は？
10. 同じような目的のアプリやサービスを今までに使ったことがありますか？(あれば、使い続けなかった理由も)
11. アレルギー対応の情報を、他の当事者やSNS・患者会から得ることはありますか？(あれば、どんな情報を、どれくらいの頻度で)

**D. コンセプトの提示と反応(ここで初めてアプリの話をする)**

> ここでアプリのコンセプトを1〜2文で説明する。「バーコードをスキャンすると、特定原材料28品目の該当有無がすぐ分かるアプリ」

12. このようなアプリがあったら、今の困りごとの何が解決しそうですか？逆に、解決しなさそうな部分はどこですか？
13. これまで挙げていただいた確認作業のうち、このアプリで代替したいと思うのはどれですか？(具体的な場面で聞く)
14. もしこのアプリが月額300円だったら使いたいと思いますか？月額500円なら？1,000円なら？(具体額を段階的に当てて反応の変化を見る)
15. 逆に、このアプリの情報が「信用できない」「怖い」と感じるとしたら、どんな場合ですか？(誤情報リスクへの感度を確認)

### インタビュー後の記録項目

各インタビュー後、以下を即座にメモする(記憶が新しいうちに):
- 最も強い痛みのエピソード(そのまま引用できる言葉で)
- 既存の代替手段とその満足度
- 価格に対する反応(即答で「安い」「高い」どちらに寄ったか)
- コンセプトへの違和感・懸念点
- Phase 2の設問に反映すべき気づき

## Phase 2: アンケート設計(50〜100人規模)

Phase 1の結果を踏まえて設問文言は調整する前提。ここでは骨格を示す。

### 実施方法の候補

- オンライン調査会社(マクロミル、Freeasy等)のアレルギー当事者パネル、または食物アレルギー関連のクラウドソーシング調査
- スクリーニング条件: 食物アレルギー当事者本人、または子どもが食物アレルギーの保護者。直近1ヶ月以内に加工食品を購入した人

### 設問構成

**スクリーニング**
- Q1. ご本人またはご家族(お子様等)に食物アレルギーの診断を受けた方はいますか？
- Q2. (いる場合)どなたが対象ですか？アレルゲンは何ですか？(複数回答)
- Q3. 直近1ヶ月以内に、スーパー・コンビニ等で加工食品を購入しましたか？

**現状の困りごと(定量化)**
- Q4. 加工食品購入時、アレルゲン表示の確認にどれくらい時間がかかりますか？(選択式: 気にしない/30秒未満/1〜3分/3分以上)
- Q5. 過去1ヶ月で「表示が分かりにくく困った」経験は何回くらいありましたか？(0回/1〜2回/3〜5回/6回以上)
- Q6. 確認の結果「買うのをやめた」経験はありますか？(ある/ない、頻度)
- Q7. 確認漏れでヒヤッとした経験は過去にありますか？(ある/ない)
- Q8. 現在の確認方法は？(複数回答: パッケージ表示のみ/メーカー公式サイト/慣れた商品のみ購入/家族・知人に聞く/SNS・患者会/その他)
- Q9. 現在の確認方法にどれくらい満足していますか？(5段階)

**コンセプト提示後の反応**
> アプリコンセプトを提示

- Q10. このアプリを使いたいと思いますか？(5段階: 絶対使わない〜絶対使う)
- Q11. 現在の確認の困りごとのうち、どの程度解決しそうですか？(5段階)
- Q12. 月額いくらまでなら払っても良いと思いますか？(単一選択: 無料でしか使わない/〜300円/〜500円/〜1,000円/1,000円以上)
- Q13. 有料版に求める機能はどれですか？(複数回答: 推奨20品目まで対応/家族の複数プロファイル管理/オフライン利用/コンタミ情報の推定表示/その他自由記述)
- Q14. このアプリの情報を信頼する上で、最も重要だと思うことは何ですか？(複数回答: 情報源の明記/更新頻度/運営者の実名・専門性/口コミ・レビュー/その他)
- Q15. (自由記述)このアプリについて、期待や不安があれば教えてください。

### 集計時に見る指標(Go/No-Go判断の目安)

- **Q10で「使いたい」「やや使いたい」の合計が過半数を超えるか**
- **Q12で「無料でしか使わない」の割合が過半数を超えていないか**(超えていれば有料モデルの再考が必要)
- **Q5・Q7で「困った経験あり」の回答者が、Q10のポジティブ回答と相関しているか**(困っている人ほど使いたいと言っているか、の整合性チェック)
- Q1・Q2の属性別(保護者/本人、アレルゲン種類別)にクロス集計し、最も反応が強いセグメントを特定する

---

## ターゲットへの当たり方(リクルーティング手順)

### Phase 1(デプスインタビュー)のリクルート

1. **知人・ソーシャルのつながり(紹介経由)**
   - まず身近なつながりから2〜3人に依頼し、その方から「他に困っていそうな人を知らないか」と紹介の連鎖(スノーボールサンプリング)をお願いする。
   - 依頼文例: 「食物アレルギーのあるお子さんを育てている方、または食物アレルギー当事者の方に、買い物時の困りごとについて30分ほどお話を伺いたく、お知り合いにいらっしゃれば紹介いただけないでしょうか」

2. **SNSの当事者コミュニティ**
   - X(旧Twitter)・Instagramで「#食物アレルギー」「#アレルギーっ子」「#卵アレルギー」等のハッシュタグを検索し、日常的に発信しているアカウントにDMで依頼する。
   - 依頼時は「営利目的の調査であること」「謝礼(Amazonギフト券等、1,000〜3,000円程度を想定)」を明示し、誠実さを示す。
   - 患者会・支援団体(例: 日本アレルギー友の会、各地のアレルギーっ子の会等)のSNSアカウントにも協力依頼を出し、団体経由での告知をお願いする選択肢もある。

3. **謝礼設計**
   - 30分の時間拘束に対して、Amazonギフト券1,000〜3,000円程度を目安に用意する。
   - 謝礼があることで依頼への応答率が上がり、特に忙しい保護者層のリクルートに有効。

4. **人数配分の目安**(15人の場合)
   - 保護者(子どものアレルギー対応): 8〜10人
   - 成人当事者本人: 5〜7人
   - アレルゲンの種類はできるだけ分散させる(卵・乳・小麦のような主要アレルゲンだけでなく、そば・落花生等の重篤度が高いものも含める)

### Phase 2(アンケート)のリクルート

1. **オンライン調査会社**を優先する。理由: 食物アレルギー当事者は母集団としては少数派(数%程度)のため、一般消費者パネルからのスクリーニングでは回収効率が悪い。アレルギー特化のパネルを持つ調査会社、または医療・健康分野に強いクラウドソーシング(例: マクロミル、Freeasy、または疾患啓発領域に強い調査会社)を優先的に検討する。
   - 想定コスト: 50〜100サンプルのスクリーニング付き調査で数万円〜十数万円程度(調査会社・条件により変動するため、複数社に見積もりを取る)。
2. Phase 1で協力してくれた患者会・SNSコミュニティに、アンケートフォーム(Googleフォーム等)の拡散協力を依頼するルートも並行して確保する。ただしSNS経由のみだと「すでに強い関心がある層」に偏るバイアスがあるため、オンライン調査会社経由のサンプルと合わせて解釈する。

### 進め方上の注意

- Phase 1とPhase 2は完全に切り分けず、Phase 1で見えた「意外な困りごと」や「使われている独自の言葉」をPhase 2の選択肢・自由記述に反映させる。
- インタビュー・アンケートいずれも、「このアプリを使うか」を直接聞く前に、必ず現状の行動・困りごとを先に聞く順序を守る(誘導バイアスを避けるため)。
- 謝礼・調査目的の説明時に、個人情報(アレルゲンの詳細等の要配慮個人情報に該当しうる情報)を扱う調査である旨を明記し、同意を得た上で実施する。
